1. 어떤 정보를 언제 사용하나요?

월급과 근무 조건
월급, 월 근무일, 하루 근무시간은 계산과 다음 방문 시 설정 복원을 위해 브라우저 웹 저장소(localStorage)에 저장합니다. 현재 서비스는 이 입력값을 Firebase 랭킹 서버에 전송하지 않습니다.
브라우저 기록
당일 타이머 상태, 시작 시각, 누적 시간, 화면 초기화 기준, 닉네임과 저장 대기 기록을 이 브라우저에 보관합니다. 대기 기록에는 날짜, 누적 시간, 닉네임과 연결된 사용자 식별자가 포함될 수 있습니다. 이전 버전에서 보관된 설정·대기 데이터가 남아 있을 수도 있습니다.
개인 달력·리포트와 목표 가격
개인 달력과 주간·월간 리포트를 위해 날짜별 누적 시간과 해당 날짜의 월급·근무 조건을 브라우저에 보관합니다. 오늘 금액은 현재 조건으로, 지난 날짜 금액은 보관된 조건으로 계산합니다. 가격을 시간으로 바꾸는 기능의 목표 이름과 가격도 같은 브라우저에 저장합니다. 이 개인 이력과 목표 정보는 Firebase에 전송하지 않으며 다른 기기와 자동 동기화하지 않습니다.
익명 인증 정보
계산기 페이지를 열면 Firebase 익명 인증을 시도합니다. 같은 브라우저의 기록을 구별하기 위한 식별자(UID)가 생성되며 인증 상태는 Firebase가 관리하는 브라우저 저장소에 보관될 수 있습니다. 일반적인 이용에 이름·이메일·비밀번호 입력을 요구하지 않습니다. 익명 인증이라는 이름이 모든 정보를 식별 불가능하게 만든다는 뜻은 아닙니다.
서버 랭킹 기록
닉네임을 저장할 때 식별자, 닉네임, 수정 시각이 저장될 수 있습니다. 루팡 기록을 확정하면 날짜별 누적 시간이 추가됩니다. 이 정보는 랭킹 표시, 중복 저장 방지, 오늘 기록 확인과 공유 비율 계산에 사용합니다.
현재 활동 상태
루팡을 시작하면 식별자, 닉네임, 활동 만료 시각과 수정 시각을 저장합니다. 실행 중 약 30초마다 상태를 갱신하고 중지 시 비활성화를 시도합니다. 현재 루팡 중인 인원 수를 집계하는 데 사용합니다.
접속·보안 정보
웹페이지 전송과 인증을 위해 Vercel과 Firebase가 IP 주소, 브라우저 정보, 요청 시각 등 접속·보안 정보를 처리할 수 있습니다. 월루미터가 월급을 서버에 저장하지 않는 것과 서비스 제공자의 접속 정보 처리는 구분됩니다.
이메일 문의
이용자가 문의를 보내면 회신 주소, 문의 내용과 이용자가 첨부한 정보를 운영자가 문의 확인과 응답을 위해 사용합니다. 문의에 월급, 비밀번호, 인증 토큰이나 불필요한 신분증 정보를 보내지 마세요.

3. 보관 기간과 삭제 방식

자정의 랭킹 전환, 활동 만료, 화면 기록 초기화는 서버 데이터 삭제가 아닙니다. 현재 서비스 코드에는 서버 랭킹·활동 문서를 일정 기간 후 자동 삭제하는 기능이 없습니다. 이전 날짜 문서와 만료된 활동 문서도 운영자가 정리하거나 삭제 요청을 처리하기 전까지 남을 수 있습니다.

월급·근무 조건·닉네임다음 방문에도 설정을 불러올 수 있도록 브라우저에 보관브라우저의 해당 사이트 데이터 삭제

화면 기록 초기화는 진행 중 기록을 멈추고 오늘 총 기록을 유지한 채 표시 구간만 새로 시작합니다. 월급 설정이나 서버 기록을 모두 지우는 버튼이 아닙니다. 반대로 브라우저 사이트 데이터 삭제는 서버 기록을 삭제하지 않으며, 인증 상태를 잃으면 같은 서버 기록에 다시 접근하기 어려울 수 있습니다.

서버 기록 삭제 요청은 운영자가 본인 기록인지 확인한 후 처리합니다. 현재 이용자용 즉시 서버 삭제 버튼은 없습니다. 서비스 제공자의 보안 로그 및 백업 제거 시점은 해당 제공자의 정책에 따르며, 문서 삭제와 모든 백업의 즉시 제거를 같은 의미로 안내하지 않습니다.

2026년 10월 29일 확인한 현재 Firestore 기본 데이터베이스의 저장 리전은 대한민국 서울(asia-northeast3)입니다. 이는 랭킹·활동 문서를 저장하는 데이터베이스의 위치이며, Firebase 인증·보안 정보나 Vercel 전송·접속 정보의 처리 위치까지 같은 지역으로 제한한다는 뜻은 아닙니다.

이들 서비스는 대한민국 외의 인프라에서도 정보를 처리할 수 있습니다. 서비스별 보관·이전 조건은 사용 중인 프로젝트 설정과 제공자 약관에 따라 달라집니다. 해당 내용에 관한 문의는 운영자가 설정을 확인해 안내합니다. 월루미터가 모든 데이터를 국내에만 보관한다고 보장하지 않습니다.

5. 광고 쿠키와 개인 맞춤 광고 선택

현재 버전의 계산기와 안내 페이지에는 AdSense 광고를 요청하는 코드가 실행되지 않습니다. 광고 시청이나 클릭은 타이머 이용 조건이 아니며, 앱은 월급·근무 조건을 외부 웹 분석 도구로 전송하지 않습니다.

향후 Google AdSense 광고를 제공하는 화면에서는 Google과 제3자 광고 제공자가 쿠키 등을 사용해 이 사이트 또는 다른 사이트의 이전 방문 기록을 바탕으로 광고를 게재할 수 있습니다. 개인 맞춤 광고 설정은 Google 내 광고 센터에서 관리할 수 있으며, 일부 제3자 광고의 선택은 Digital Advertising Alliance의 광고 선택 페이지에서 확인할 수 있습니다.

브라우저 설정에서 쿠키나 사이트 저장소를 차단·삭제할 수도 있습니다. 이 경우 설정 복원, 익명 인증, 저장 대기 기록 유지 등이 제한될 수 있습니다. 광고 기능을 다시 제공할 때는 해당 지역의 동의 요건과 광고 제공 범위를 확인하고 이 안내를 갱신합니다.
